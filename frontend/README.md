# Frontend

React and Vite application for the Phase 1 landing page. The connection indicator reflects the actual response from `GET /health`; it does not display simulated machine data.

## Commands

```powershell
npm install
npm run dev
npm run build
npm run preview
```

Set `VITE_API_BASE_URL` in `.env` to the versioned backend API base URL. The default is `http://localhost:3000/api/v1`.
